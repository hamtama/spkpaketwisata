## Pengenalan APlikasi

Aplikasi ini merupakan Sistem Pendukung Keputusan (SPK) berbasis web menggunakan Laravel yang membantu pengguna memilih paket wisata terbaik berdasarkan kriteria tertentu, menggunakan algoritma K-Nearest Neighbor (KNN) dengan metode Euclidean Distance. 🦊

<a name="section-2"></a>
## Tujuan Sistem Dibangun

- Membantu user menemukan paket wisata yang paling sesuai dengan kebutuhan mereka.
- Menyediakan hasil rekomendasi cepat, akurat, dan user-friendly.
- Menjadi sistem berbasis web yang aman, modular, dan scalable.

<a name="section-3"></a>
## Paramenter Pendukung Keputusan
- Lokasi Wisata (Misal: Bali, Yogyakarta, Semarang, Bandung, Malang, dsb)
- Budget (Dalam IDR)
- Durasi (Dalam Hari)
- Jenis Wisata (Alam, Sejarah, Kuliner, Budaya, Adventure, dsb)
- Fasilitas (Hotel, Transportasi, Tour Guide, Makan, Tiket Basuk, dsb)
- Jumlah Peserta (Berapa Banyak Orang)

<a name="section-4"></a>
## Fitur Utama
### Admin
- Authentication & Authorization (Login Admin/User)
- Dashboard Admin (Lihat data Inputan, Paket Wisata, Hasil Rekomendasi)
- Management Data User (Admin Side)

### Data Testing
- Simulisasi Perhitungan

### Data Master
- Manajement Data Jenis Paket
- Manajement Data Lokasi
- Manajement Data Fasilitas
- Manajement Data Transportasi
- Manajement Data Restaurant
- Manajement Paket Wisata
